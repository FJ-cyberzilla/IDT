⏳ Time-Diag Module & NetworkWorkflowEngine

The time-diag module orchestrates synchronized, chronological network and DNS diagnostic test sequences. It immediately communicates both the chronological aspect (exact timestamps, duration, sequence indexing) and the diagnostic purpose of handling network tests across DoH, DoT, and Standard protocols.

🔄 Synchronized Concurrency

Utilizes bounded semaphores and sync.RWMutex to execute concurrent probes without thread contention or socket exhaustion.

🛡️ Error & Helper Integration

Integrates errorhandling.ResolveError for granular error categorization and helper.Retry with jittered backoff for transient recovery.

📊 Live Dashboard Telemetry

Feeds chronological event reports directly into the Bubble Tea TUI dashboard (`stateTimeDiagRunning`, `stateTimeDiagResults`) for live inspection.

IDT is rigorously structured into 15 cohesive, decoupled Go internal packages adhering to absolute modularity and 100% test coverage:

checkHealth
Real-world connectivity checks and policy compliance anchor verification.
cmdCobra
Root command center launcher, CLI flags, and subcommand execution routing.
compareDiff
Side-by-side DNS provider benchmarking, IP observation, and oracle diffing.
configPolicy
Master configuration loader, servers catalog, security policies, and system DNS discovery.
dialerTransport
Multi-protocol transport stack (DoH, DoT with DPI bypass TLS fragmentation, Standard UDP/TCP, wire parser).
enterpriseSimulation
Distributed office performance matrices, multi-protocol testing, live traffic replay, and DNSSEC audits.
errorhandlingResilience
Granular error classification (NetworkErrorDetails), Android Private DNS detection, and robust fallback lookups.
guardcatWatchdog
Auto-finetuning, memory state monitoring, health tracking, DNS EOF trigger thresholds, and circuit breaking.
helperPrimitives
Panic-recovering concurrency (SafeRun, SafeGo), retry jitter, and shared transport connection pooling.
outputRendering
Formatted terminal output tables and ANSI/ASCII telemetry renderers.
runnerExecution
Concurrent benchmark execution engine with sliding window DNS EOF Reconnect Detection.
statsMetrics
Statistical aggregation of RTT percentiles, arithmetic mean, and standard deviation.
time-diagWorkflow
Synchronized chronological network and DNS diagnostic test sequences via NetworkWorkflowEngine.
tuneOptimization
Automated RTT distribution analysis, performance tuning, and resolver eligibility filtering.
uiTUI
Bubble Tea interactive dashboard state machine, Lip Gloss theme system, and modular visual components.
vaultStorage
Encrypted datalist candidate loader (AES-256-GCM), warm-up probing, live pool manager, and JSONL loggers.

🌐 Remote Office Matrix

Concurrently simulates latency, jitter, and packet loss across distributed global data centers (New York, London, Tokyo, Frankfurt, Sydney).

📡 Multi-Protocol Probing

Tests HTTP APIs, VoIP/SIP-RTP, SaaS (M365, Salesforce), and custom app protocols under high congestion and dropped packet conditions.

📼 Traffic Replay Simulator

Captures production transactions and replays them in lab settings with speed multipliers and jitter injection for safe deployments.

🔐 AES-256-GCM Encryption

Candidate seed resolver lists in datalist/ can be encrypted securely at rest and decrypted transparently at runtime.

📝 JSONL Instrumentation

Append-only audit logging recording warm-ups, test probes, and live pool snapshots into gitignored runs/ directories.

🛡️ Graceful Fallback Chain

If seed files are absent on fresh clones, the live pool gracefully initializes robust built-in fallbacks (Cloudflare, Google, Quad9).
