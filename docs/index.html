IDT — Internet Dialer Test

A signal finder for your internet dialer. Measure which public DNS resolver is fastest and most reliable from your device — then point your device at it.

Built by FJ Cyberzilla

What IDT does

Point. Read. Adjust.

You use IDT the same way you use a satellite signal finder: point at public infrastructure, read the signal, adjust your device. Nothing more, nothing less.

📡

Measures round-trip time

Dials public DNS resolvers over DoH, DoT, and standard port 53. Records the actual round-trip in milliseconds — no estimates, no fabricated numbers.

🔒

Compares encrypted paths

Queries the same domain through encrypted and unencrypted channels. If the answers disagree, something between you and the resolver is answering on its behalf.

📊

Ranks by real performance

Reports median, p90, and jitter per resolver. Sorted fastest-first. Colour-coded so you can read the table in two seconds.

⚙️

Prints the exact setting

For Android Private DNS, IDT gives you the exact hostname to paste. No guessing, no lookup tables, no copy-pasting from forum posts.

🌍

Eight providers, three protocols

Cloudflare, Google, Quad9, OpenDNS, AdGuard, Mullvad, CIRA, ControlD — tested over DoH, DoT, and port 53.

🛡️

Gentle on the network

Five dials in check mode. Seventy-two in full mode, spread over 40 seconds with jitter. Below the noise floor of any VPN exit.

What IDT does not do

Signal finder, not a weapon

A signal finder measures the strength of a broadcast. It doesn't intercept, decrypt, or jam anything. IDT is the same category of tool.

✕

No network scanning

IDT sends DNS queries. It does not scan ports, sweep ranges, or probe hosts.

✕

No traffic interception

IDT observes round-trip time. It does not capture, decrypt, or replay anyone's traffic.

✕

No authentication bypass

IDT uses the same public DNS endpoints any device uses. Nothing is bypassed.

✕

No private data access

IDT dials example.com by default — an IANA-reserved domain with zero commercial value.

Usage

Install and run

Zero dependencies. Pure Go. Compiles in seconds on Termux, Linux, or macOS.

install 
# Clone and build
git clone https://github.com/FJ-cyberzilla/IDT.git
cd IDT
go build -o idt .

# Daily driver — 5 dials, plain-English verdict
./idt -check

# Full tune-up — benchmark 8 providers × 3 protocols
./idt -tune

# Filter by what you value
./idt -tune -dial privacy
./idt -tune -dial no-logging
./idt -tune -dial blocking

# Plan without sending packets
./idt -plan

# Compare VPN on vs off
./idt -tag "no-vpn" -tune > run-no-vpn.txt
./idt -tag "vpn-on" -tune > run-vpn-on.txt
diff run-no-vpn.txt run-vpn-on.txt
