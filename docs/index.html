Core Module Architecture

IDT is organized into decoupled, highly cohesive packages under `internal/` and `configs/`:

  • `configs/`: Production default master configuration module and serialization tests.
  • `internal/cmd/`: Cobra root command center and subcommand routing.
  • `internal/ui/`: Bubble Tea TUI state machine, theme system (`theme.go`), and modular renderers (`visual.go`).
  • `internal/dialer/`: Multi-protocol transport stack (DoH, DoT, Standard, wire encoding, parsing).
  • `internal/helper/`: Concurrency primitives (`SafeRun`, `SafeGo`), retry jitter, and shared connection pooling.
  • `internal/errorhandling/`: Granular error classification and remediation engine.
  • `internal/runner/`, `internal/stats/`, `internal/check/`, `internal/tune/`, `internal/compare/`: Analytics and benchmarking engines.

🔒 Zero-Logging Guarantee

IDT does not log, collect, transmit, or store any user queries, IP addresses, or telemetry data. All calculations execute locally.

🔐 TLS 1.3 Enforcement

All DoH and DoT connections enforce strict TLS minimum standards with rigorous certificate validation against system trust stores.

🛡️ RFC Compliance

Strict adherence to RFC 8484 (DoH) and RFC 7858 (DoT) wire formatting and security specifications.
